# Dataset

Для выполнения HW1 используется датасет **UNSW-NB15**.

Датасет содержит сетевые соединения и признаки, описывающие
характеристики сетевого трафика. В рамках проекта задача
формулируется как бинарная классификация:

- `0` — нормальный трафик;
- `1` — сетевое соединение, относящееся к атаке.

Используемые файлы:

- `UNSW_NB15_training-set.csv` — тренировочная выборка;
- `UNSW_NB15_testing-set.csv` — тестовая выборка.

CSV-файлы не хранятся в Git-репозитории из-за их размера.
Для запуска ноутбука необходимо предварительно разместить
их в данной директории.

> `id` используется только как идентификатор записи и не
> рассматривается как признак модели. `attack_cat` используется
> для разведочного анализа, но не используется как признак
> бинарной классификации, поскольку непосредственно связан
> с типом атаки.
