# ML Network Intrusion Detection

Учебный проект по машинному обучению и анализу данных в области информационной безопасности.

Проект посвящён применению методов машинного обучения для **обнаружения сетевых атак (Network Intrusion Detection)**.

## Цель проекта

Разработать и исследовать модель машинного обучения, способную классифицировать сетевой трафик как:

* `0` — нормальный трафик;
* `1` — сетевую атаку.

В рамках проекта постепенно выполняются этапы анализа данных, подготовки признаков, построения и оценки моделей машинного обучения.

## Датасет

В проекте используется датасет **UNSW-NB15**, содержащий характеристики сетевых соединений и различные типы сетевых атак.

Основные файлы датасета:

* `UNSW_NB15_training-set.csv` — тренировочная выборка;
* `UNSW_NB15_testing-set.csv` — тестовая выборка.

Описание размещения и использования датасета находится в [`data/README.md`](data/README.md).

Сами CSV-файлы не хранятся в Git-репозитории.

## HW1 — Exploratory Data Analysis

Первая домашняя работа посвящена постановке задачи и разведочному анализу датасета UNSW-NB15.

В рамках HW1 выполнены:

* формулировка задачи обнаружения сетевых атак;
* определение задачи бинарной классификации;
* анализ распределения целевой переменной;
* исследование категориальных признаков;
* анализ числовых признаков;
* исследование выбросов и асимметрии распределений;
* анализ корреляций между признаками;
* интерпретация результатов с точки зрения информационной безопасности.

Основной ноутбук:

[`hw_1/eda.ipynb`](hw_1/eda.ipynb)
